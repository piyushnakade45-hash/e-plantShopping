# Paradise Nursery

**Project Name:** Paradise Nursery – Online Plant Shopping Application

## About the Project
Paradise Nursery is a shopping cart web application for an online houseplant shop. It is built with **React** and **Redux Toolkit**, and users can browse plants, add them to a cart, and manage their order.

## Features
- **Landing page** with a background image, the company name, a short paragraph about the company, and a "Get Started" button
- **Product listing page** with houseplants grouped into three categories, each showing a thumbnail, name, and price
- **Add to Cart** button on every plant, which is disabled once the plant is added
- **Navigation bar** with Home, Plants, and Cart links, and a cart icon showing the total number of items
- **Shopping cart page** showing each plant's thumbnail, name, unit price, and subtotal, along with the total number of plants and the total cart amount
- Buttons to **increase**, **decrease**, and **delete** items, plus **Checkout** ("Coming Soon") and **Continue Shopping**

## Technologies Used
- React (Vite)
- Redux Toolkit and React-Redux
- JavaScript (JSX), CSS
